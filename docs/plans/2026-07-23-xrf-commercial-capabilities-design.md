# XRF Gen2 commercial capabilities module

The existing `project-showcase` becomes a self-contained commercial narrative at `#capabilities` without removing the later engineering proof chapters. The module keeps the existing 1280 px editorial grid, Certia typography, white and `#F5F5F7` surfaces, 32 px media radii, restrained dividers and OneLaser red only for state and CTA accents.

The first layer is a four-slide finished-product carousel. It retains the current split image-and-copy anatomy while adding automatic advancement, hover pause, timer reset after manual input, keyboard navigation, touch swipe and a reduced-motion path. The second layer is a tabbed Product Opportunities explorer. One active category renders a single existing product-proof scene, three semantic product buttons and a stable Example Economics panel. Category, product and economics content lives in centralized data objects so figures and claims are not duplicated across JSX. The third layer bridges the finished products back to four already-confirmed XRF capabilities, then provides CTA anchors to the existing purchase and power-comparison sections.

The implementation reuses existing local proof images rather than embedding the reference artwork or hotlinking new assets. `material-wood.webp` is already a close match for Home & Outdoor Décor. The Leather, coated-metal and acrylic scenes are safe temporary category proofs and are explicitly marked in the data for later replacement by dedicated approved category photography. The old long-form capability browser is retained as `#capability-system` so no validated engineering content is lost.
