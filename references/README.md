# Temporary visual references

Put screenshots and temporary user-supplied visual references in `references/incoming/` so future tasks can inspect a stable local path instead of decoding images from old task logs.

- `references/incoming/` is ignored by Git and may contain temporary files.
- Move only approved production assets to `public/assets/` with a descriptive stable filename.
- Do not copy reference images into `qa/`; existing QA files are preserved evidence.
- Delete temporary references only when the user explicitly asks or confirms they are no longer needed.
